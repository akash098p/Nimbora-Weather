# Nimbora Weather

A modern weather forecasting website inspired by the supplied weather-app interface.

## Initial structure

- `index.html` — application shell and dashboard sections
- `src/styles.css` — responsive glass/weather UI
- `src/app.js` — initial forecast data rendering

## Roadmap

1. Match the reference UI precisely across mobile and desktop.
2. Add live weather API integration.
3. Add location search and browser geolocation.
4. Add hourly and multi-day forecast data.
5. Add weather alerts, AQI and detailed metrics.
6. Add maps/radar and advanced forecast views.
7. Add PWA support and deployment.
